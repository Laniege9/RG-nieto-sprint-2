RG Nieto Sitio web institucional (Sprint III)

Proyecto web
Requerimientos
HTML5 / CSS3
Bootstrap 5.3 (componentes de Preguntas frecuentes, Blog y Contacto)
JavaScript
Google Fonts (Montserrat) y Font Awesome 6.5.2

Estructura:
index.html           Inicio: catálogo por categorías y buscador
nosotros.html       Historia, misión, visión y valores
servicios.html        Servicios, portafolio (carrusel) y galería
blog.html           Artículos del blog
faq.html             Preguntas frecuentes
contacto.html       Sucursales, canales de contacto y formulario
css/tipografia.css     Sistema tipográfico (Manual de Identidad Visual)
css/estilos.css     Encabezado, menú, banner, buscador y pie de página
css/persona2.css      Componentes: tarjetas, galería, carrusel, Nosotros
css/paginas.css     Elementos comunes de Blog, Preguntas frecuentes y Contacto
css/estilos-persona3.css  Componentes Bootstrap personalizados (tarjetas, acordeón, tablas, formulario)
css/responsivo.css  Ajustes para tabletas (768 px) y celulares (480 px)
js/navegacion.js        Menú móvil, submenú de productos y buscador
js/carrusel.js       Carrusel del portafolio
js/contacto.js      Validación del formulario de contacto
img/                 Logotipos, banner, productos y galería

Sobre la Tipografía:
La tipografía oficial de la marca es Gotham pero no pude conseguir la versión web asi que
el sitio usa montserrat (que el manual de Identidad Visual define como la
alternativa más cercana a Gotham) las equivalencias de pesos y tamaños están
documentadas en "css/tipografia.css"
